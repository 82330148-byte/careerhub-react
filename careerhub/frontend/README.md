# CareerHub – Job Finder Platform

CareerHub is a responsive job finder web application built using React.

The platform allows users to browse available jobs, search by job title,
filter jobs by type, save preferred jobs, view complete job details, and
submit job applications.

## Features

- Responsive navigation bar
- Multiple pages using React Router
- Browse available jobs
- Search jobs by title
- Filter jobs by job type
- Save jobs using localStorage
- Remove saved jobs
- Dynamic job details pages
- Job application form
- Contact form
- Responsive design
- Custom 404 page

## Pages

- Home
- Jobs
- Saved Jobs
- Job Details
- Apply
- About
- Contact
- 404 Not Found
